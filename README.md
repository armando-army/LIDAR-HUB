# ARMANDO FREZZE DURAND · Proyectos interactivos

Hub online de Armando Frezze Durand. Abrí las obras con mouse o pantalla táctil.

Para usar el sensor LiDAR, iniciá LiDAR Studio en la computadora conectada al sensor y abrí la obra desde el hub local. El servicio USB no se ejecuta en GitHub Pages.

Este repositorio contiene únicamente la web publicada y sus recursos. El código de la aplicación local se conserva en LIDAR-STUDIO.
